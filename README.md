# Receitas da Lorena

Modelo de site simples de Receitas.

## Finalidade

Um site de receitas para testes de layout.

## Funcionalidades

- Navegação otimizada
- Paginação
- Acesso a diversas receitas

## Estrutura de pastas

```
lib/
├── estilos/       # Arquivos de estilização do site
├── imagens/       # Imagens utilizadas no site
├── receitas/      # Receitas individuais
└── index.html     # Ponto de entrada
```

## Como utilizar

```bash
# 1. Clone o repositório
git clone https://github.com/Roger-snts/receitas.git

# 2. Acesse a pasta do projeto
cd receitas

# 3. Instale as dependências
flutter pub get

# 4. Execute o app
flutter run
```


## Como acessar
Acesso Web: [Receitas da Lorena](https://roger-snts.github.io/Receitas/)

## O que aprendi

HTML e CSS básicos. Aprendi a montar o escopo de uma página web, criar carrosseis de imagens, paginação e estilização.
